WingsPay - Modern Payment Solutions
 Project Overview
 WingsPay is a sleek, modern landing site that presents a full suite payment solution for businesses of
 all sizes — enabling them to accept payments, send payouts, automate financial workflows, and grow
 globally.
 Key Features- Instant settlements — get your money in real time.- Bank grade security: PCI DSS Level 1 certified, advanced fraud detection.- Global coverage: Accept payments from 150+ countries and 100+ currencies.- Smart analytics via a real time dashboard for data driven decisions.- Mobile optimized: Seamless experience across all devices.- Full payment suite:
 * Payment Gateway (cards, wallets, UPI)
 * Payouts (bulk transfers, multi currency support)
 * Subscriptions / Recurring billing
 * Business banking (current accounts, corporate cards)
 * Payment links & invoices
 Tech Stack- HTML5 / CSS3 / JavaScript- Responsive design (mobile first)- Deployed on GitHub Pages using the repository nitinsharma1711/WingsPay
